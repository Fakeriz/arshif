# Arshif

Asisten keuangan pribadi berbasis AI untuk pekerja lintas negara (ID/MY/TR) — catat transaksi < 10 detik lewat foto struk, suara, atau rekening koran PDF; multi-mata uang IDR/MYR/TRY/USD.

Stack: Expo SDK 58 (Expo Router, TypeScript strict) + Supabase (mulai Fase 2).

```bash
npm ci
npm run web      # Lembar Desain di /design
npm run verify   # typecheck + test + export semua platform
```

Status & keputusan: lihat [PROGRESS.md](./PROGRESS.md). Spesifikasi: [`docs/`](./docs).
